# Security and privacy

## Reporting a vulnerability

Please report security issues privately through GitHub's security-advisory feature. Do not include credentials, real resumes, candidate photographs, or other personal data in a public issue.

## Personal-data incidents

Treat an accidentally committed resume or derived candidate record as a privacy incident. Remove public access, rotate any exposed credentials, purge the data from Git history, and notify affected people when appropriate.

## Supported version

Security fixes are applied to the latest revision of the `main` branch.
